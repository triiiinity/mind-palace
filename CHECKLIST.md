# mind palace — checklist

## get it online
- [ ] GitHub → New repository → name `mind-palace` → empty, no README → create
- [ ] upload this folder's files into it (or tell Claude the repo exists and it pushes them)
- [ ] Cloudflare → Workers & Pages → Create → Import a repository → pick `mind-palace` → Deploy
- [ ] open https://mind-palace.trinityl-lester.workers.dev and check it loads
- [ ] carry your saved stuff over: on each computer/phone you used the old room on, open trinitylester…/room-q7x4.html → download backup → on mind palace: 2 · image feed → bottom → restore
- [ ] once restored everywhere: delete room-q7x4.html from the portfolio
